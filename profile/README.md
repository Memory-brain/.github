## MemoryBrain

**A personal memory for ChatGPT and Claude that you own, with the source of every note.**

MemoryBrain remembers what you are working on, what you read and how you like to work, and brings it into the conversation when it helps. The same memory works in ChatGPT and Claude, so your context is not locked to one provider. Every note keeps where it came from: something you read, a chat, or something you said.

- **Website:** [memorybrain.ai](https://memorybrain.ai/?ref=github)
- **Remote MCP server:** `https://app.memorybrain.ai/mcp` (OAuth, nothing to install). Listed in the official MCP Registry as `ai.memorybrain/memorybrain`.
- **Connect it:** [same memory in ChatGPT and Claude](https://memorybrain.ai/guides/same-memory-chatgpt-claude/?ref=github) · [for AI assistants](https://memorybrain.ai/agents.md)
- **Try it without an account:** [demo](https://app.memorybrain.ai/demo)

MemoryBrain is in private beta: [join the waitlist](https://memorybrain.ai/?ref=github#waitlist).

### Open Brain

MemoryBrain is built on **[Open Brain](https://github.com/Memory-brain/open-brain)**, an open method for building a second brain that AI can use: how notes are extracted, linked and kept with their source. The method and its Claude Code skills are open source.

### Name

MemoryBrain (memorybrain.ai) is built by [Carlos Moya](https://www.linkedin.com/in/csmoya/). It is not related to memorybrain.in, a different product with a similar name.
